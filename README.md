# Benjamin Nii Aryee — Portfolio

Personal portfolio site for Benjamin Nii Aryee, a frontend developer based in Amasaman, Accra, Ghana.

**Live:** https://philonii.github.io/my-portforlio/

## Built with

- HTML5
- CSS3 (custom properties, Flexbox, CSS Grid, media queries)
- Font Awesome for icons, Google Fonts (Poppins)
- Hosted on GitHub Pages

No build step — `index.html` and `style.css` are served directly.

## Running locally

```bash
git clone https://github.com/PhiloNii/my-portforlio.git
cd my-portforlio
python3 -m http.server 8000
```

Then open http://localhost:8000
